Schematic API (自动连线!)

API 说明 需要坐标?
add_instance(lib, cell, xy) 放置实例 ✅ 需要
add_wire(points) 画线 ✅ 需要
add_net_label_to_instance_term(inst, term, net) 标签终端 ❌ 自动!
add_wire_between_instance_terms(i1, t1, i2, t2) 连接终端 ❌ 自动!
add_pin_to_instance_term(inst, term, pin) 创建引脚 ❌ 自动!

使用示例

# 连接 from virtuoso_bridge import VirtuosoClient client = VirtuosoClient.local(port=65432) # Schematic 编辑 with client.schematic.edit("lib", "cell") as sch: sch.add_instance("gpdk090", "nmos1v", (0, 0), "R0", name="M1") sch.add_net_label_to_instance_term("M1", "D", "DRAIN") # 自动! sch.add_wire_between_instance_terms("M1", "D", "M2", "S") # 自动!

结论

两者都基于相同的 Cadence SKILL IPC 机制 (ipcBeginProcess + evalstring)，但：

  • skillbridge: 轻量级，Pythonic，适合本地交互式使用
  • virtuoso-bridge-lite: 功能丰富，远程支持，AI Agent 友好
